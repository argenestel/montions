# Montions

Outcome-first binary options on Monad with a **fully onchain central limit order book**.

> "I want to make $1,000 if MON ends above $1.50 by Friday."

Everything that touches money is a contract: order book, collateral, TWAP oracle pools, fair-value model, market-making vault,
and the read views the UI uses. See [`docs/SPEC.md`](docs/SPEC.md).

Status: work in progress (Monad Metropolis hackathon, Finance track). Demo oracle pools and tokens are **MOCK/DEMO**.
